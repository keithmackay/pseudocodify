- **Wrong project.** See "Limits of this run" above.
- **Playwright vs. manual testing.** The E2E section says "**Playwright** (preferred) or manual testing". Later sections say to use Playwright *instead of* manual testing and to replace every "manual testing" step. Which rule wins is Keith's decision.
- **Coverage metric not named (P5).** "Test Coverage Requirements" gives 100% / ≥90% / ≥80% thresholds without saying whether they mean line or branch coverage, while the pyramid section uses line coverage for unit tests and branch coverage for widget tests. This repo has no Flutter coverage config to settle it, so the original wording is kept.

The two may agree, for example if Playwright's `testDir` is `test/`, but this repo has no Playwright config to check against, so the original command is kept.
